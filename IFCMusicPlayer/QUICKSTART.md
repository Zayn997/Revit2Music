# Quick Start Guide - IFC Music Player

This guide will help you get the IFC Music Player app up and running quickly.

## Installation & Setup

### 1. Install Dependencies

```bash
cd IFCMusicPlayer
npm install
```

This will install all required packages including:

- Expo framework
- React Navigation
- expo-audio for music playback
- expo-file-system for file management
- expo-document-picker for importing files

### 2. Start the Development Server

```bash
npm start
```

This opens the Expo development tools in your browser.

### 3. Run on Device/Emulator

#### Option A: Using Expo Go (Easiest)

1. Install "Expo Go" app on your phone from App Store or Play Store
2. Scan the QR code shown in the terminal
3. App will load on your device

#### Option B: Android Emulator

```bash
npm run android
```

#### Option C: iOS Simulator (Mac only)

```bash
npm run ios
```

## First-Time Use

### Step 1: Generate Music from IFC Files

Before using the mobile app, you need music files. Use the Python converter:

```bash
cd ../ifc_to_music_converter
python main.py input.ifc
```

This generates:

- Music file (MP3/WAV)
- Optional metadata JSON file

### Step 2: Transfer Files to Device

**Method 1: Direct File Access**

- Connect device via USB
- Copy files to device storage
- Use document picker in app to import

**Method 2: Cloud Storage**

- Upload to Google Drive/Dropbox
- Download on mobile device
- Import into app

**Method 3: Email/Messaging**

- Email the music file to yourself
- Download on mobile
- Import into app

### Step 3: Import Music into App

1. Open IFC Music Player
2. Go to "Library" tab
3. Tap "+ Import" button
4. Select your music file
5. File is copied to app storage

### Step 4: Play Your Architectural Music!

1. Tap on any track in your library
2. Music starts playing automatically
3. View building metadata (if available)
4. Use playback controls

## App Features Overview

### Library Screen

- **Import Button**: Add new music files
- **Track List**: All imported music
- **Delete**: Long press or swipe to delete
- **Pull to Refresh**: Reload library

### Player Screen

- **Play/Pause**: Control playback
- **Seek Bar**: Jump to different parts
- **Metadata Display**: Building information
  - Project name
  - Elements mapped count
  - Musical key & tempo
- **Element Breakdown**: See which building elements create which sounds

### Settings Screen

- **Audio Quality**: Adjust playback quality
- **Clear Cache**: Free up storage
- **About**: App information

## File Format Support

### Audio Files

- ✅ MP3 (recommended)
- ✅ WAV
- ✅ MIDI (basic support)

### Metadata Files

- ✅ JSON format
- Must match the track filename
- Contains building and mapping information

## Troubleshooting

### App Won't Start

```bash
# Clear cache and reinstall
rm -rf node_modules
npm install
npm start -- --clear
```

### Audio Not Playing

- Check file format (MP3/WAV recommended)
- Ensure file isn't corrupted
- Check device volume and mute switch
- Try reimporting the file

### File Import Fails

- Check file permissions
- Ensure sufficient storage space
- Try a smaller file first
- Check file format is supported

### No Metadata Showing

- Metadata JSON file is optional
- Ensure JSON file was generated by Python converter
- JSON file must be imported separately
- File must be valid JSON format

## Tips & Best Practices

1. **File Naming**: Use descriptive names for your tracks (e.g., "OfficeBuilding_FloorPlan_2024.mp3")

2. **Metadata**: Always import the companion JSON file for full experience

3. **Organization**: Keep related files together before importing

4. **File Size**: Compress large audio files before importing to save space

5. **Backup**: The app stores files internally, so back up important tracks
